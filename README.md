# Fábrica de Video 🎬

**De cero a un reel profesional, gratis, con tu marca y tu avatar.** Un paquete de 8 skills para Claude Code creado por **Hugo López · El Marketero del Pueblo** para emprendedores de cualquier nicho.

1. **Clips gratis**: grábate o genera tus clips con tu avatar (tu rostro y tu voz) en **Omni Flash de Google Flow**. La Fábrica te da el plan de tomas y los prompts listos para tu negocio.
2. **Edición profesional**: subtítulos, gráficos, zooms, música y audio a −14 LUFS, todo hecho por Claude.

📖 **Guía paso a paso:** https://claude.ai/artifact/SkffRZWgqBdcLBUPUwjZdu

## Cómo usar esta plantilla
1. Arriba a la derecha, pulsa **Use this template → Create a new repository** (o **Code → Download ZIP**).
2. Descarga tu copia y descomprímela en el Escritorio.
3. Abre **Claude Code** dentro de la carpeta y pega el *Prompt 1* de [`PROMPT-DE-INSTALACION.md`](PROMPT-DE-INSTALACION.md).
4. Crea una carpeta `Reels con Claude` en Documentos, abre Claude Code ahí y escribe: **Quiero empezar con la Fábrica de Video**

No necesitas saber programar: el asistente instala lo que falte y te guía un paso a la vez.

## Qué trae
| Skill | Para qué |
|---|---|
| `fabrica-de-video` | El director del proceso |
| `omni-flash-prompts` | Clips gratis con tu avatar en Google Flow, para 11 nichos |
| `fv-diagnostico` | Revisa tu equipo e instala lo que falte |
| `fv-marca` | Tu estilo: logo, colores, tipografía, cierre |
| `fv-medios` | Une clips, quita silencios, transcribe |
| `fv-sonido` | Voz limpia, efectos, música, mezcla |
| `fv-editor` | Del plan aprobado al video |
| `fv-calidad` | Revisión y render |
